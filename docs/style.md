# 그림체

그림체는 판 어긋난 리소 스티커. 사진 → 리소 2판 변환이 시그니처(설계서 기술 구조 참고).

## 판 어긋난 리소 스티커  (Riso Misprint Sticker)

형광 핑크·블루 2도 리소 판이 어긋난 채 인쇄된 스티커가 폴라로이드를 찢고 튀어나온다.

**안 겹치는 이유**: 펫 스티커 앱은 파스텔·3D 일색이다. 형광 2도 + 판 어긋남 + 종이 그레인 조합은 쓰는 곳이 없다.

**시그니처**: ① 핑크 면과 블루 선이 늘 (+6,+5)px 어긋남 ② 모든 컷 바깥에 점선 재단선 + 구석에 2색 레지스트레이션 마크.

**박진감**: 13° 기운 머리, 프레임 구멍에서 사방으로 튀는 파편, 머리 쪽으로 모이는 속도선, 화면 밖으로 뻗는 앞발.

**팔레트**: #f3ede0 #ff4fa3 #2f4fb8 #ffd400

**제작 규칙**: 판은 핑크(면)·블루(선·그림자) 2개만, 둘 다 mix-blend-mode:multiply. 블루 판은 translate(6,5). 겹친 곳에 생기는 보라가 3번째 색. 노랑은 배경 집중선에만 쓴다. 질감은 feTurbulence 알파 마스크(잉크 빠짐) + 전체 그레인 35%. 사진 결합: 컷아웃 사진을 그레이스케일 → 레벨 보정 후 ① 핑크 판 = 사진 명도를 하프톤 도트로(패턴 마스크) ② 블루 판 = 엣지 검출 선(Sobel) 또는 윤곽선 5px. 두 판을 6px 어긋나게 겹치고 바깥에 흰 테두리 11px + 점선 재단선을 두르면 완성. 표정 12종은 블루 판 위에 눈·입 벡터 파츠만 바꿔 얹는다.
