# 0002. 리소 명도 보정에 국소 대비 평활화(CLAHE) 사용

- 날짜: 2026-11-09
- 상태: 채택
- 관련: `lib/riso/riso.dart` `_localContrast`, 이슈 #4, 리스크 "검은 털·배경 비슷한 색"

## 문제
전역 대비(상하위 2% 늘리기)만 쓰면 검은 털 사진에서 몸 대부분이 블루 그림자 판 + 진한 핑크로 덮여
남보라 덩어리가 되고 눈·얼굴이 사라졌다. 눈 하이라이트가 상위 2%를 차지하면 털은 거의 늘어나지 않는다.

## 평가 방법 (다시 돌릴 수 있음)
- 표본: Oxford-IIIT Pet 시험 세트 36장(검은 털 12, 흰 털 12, 그 외 12), 정답 분할 마스크로 누끼 → `tool/eval/fetch_pets.py`
- 지표(`tool/eval/metrics.py`, 실루엣 안쪽만):
  - dark: 출력 명도 0.35 미만 비율(덩어리, 낮을수록 좋음 — 단 눈·코 같은 진한 점은 필요)
  - detail: σ3−σ9 대역 통과 크기(망점보다 큰 구조: 눈·털결)
  - range: σ6 블러 명도의 5~95 백분위 폭(명암 단계)
- 눈 비교 시트(원본·기존·후보)로 최종 판단

## 결과
| 방식 | 검은 털 dark / detail / range | 흰 털 | 그 외 |
|---|---|---|---|
| 기존(전역 대비) | 0.390 / 0.0419 / 0.381 | 0.041 / 0.0297 / 0.366 | 0.142 / 0.0388 / 0.464 |
| **채택: CLAHE clip 2.5, 100%, 그림자 0.22** | **0.239 / 0.0454 / 0.415** | 0.068 / 0.0365 / 0.407 | 0.128 / 0.0453 / 0.454 |
| CLAHE clip 3.5, 그림자 0.15 | 0.155 / 0.0418 / 0.369 | 0.061 / 0.0360 / 0.382 | 0.101 / 0.0431 / 0.408 |

격자 탐색 6조합 중 채택안이 세 그룹 모두 detail·range 최고. 그림자 임계를 낮추면 덩어리는 더 줄지만
명암 폭이 줄어 얼굴이 밋밋해졌다(눈 비교). 흰 털은 털결이 더 살고 깨끗함 유지.
속도: AOT 89 → 98ms(+10%).

## 결정
- 전역 대비 → CLAHE(4×4 칸, 64단계, 상한 2.5) 순서로 적용, 평활화 결과를 그대로 쓴다.
- 그림자 판 임계 0.22 유지.
- 회귀 테스트: 눈 하이라이트가 대비를 독점하는 합성 검은 털에서 덩어리 비율 < 50%(기존 82%, 채택 40%).
