# H0 분할 측정

가설 H0: ML Kit 분할이 반려동물 사진에서 쓸 만하다.
판정: 사진 중 수정 없이 OK ≥ 80%, 중급기 분할 중앙값 ≤ 1.5초(첫 추론 제외), 표본 20장 이상.

## 측정 방법
1. 직접 찍은 반려동물 사진 30장을 준비한다. 시안의 위키미디어 사진은 쓰지 않는다.
   - 강아지·고양이 섞기, 검은 털 3장 이상, 배경과 털색이 비슷한 사진 3장 이상, 흐리거나 어두운 사진 2장 이상
2. 앱 → "H0 분할 측정" → 기기 이름 입력 → 사진 고르기(최대 30장).
3. 오린 결과를 보고 그대로 스티커로 쓸 만하면 OK, 털 끝 몇 가닥 외에 눈에 띄는 잘림·남은 배경이 있으면 NG.
4. 오른쪽 위 복사 버튼 → 아래 "결과"에 기기별로 붙인다.
5. 기기 2대(중급기 1, 저사양 RAM 3~4GB 1)에서 반복한다.
6. 스파이크 화면에서 사진 3장 정도로 "리소 변환 (CPU)" 시간도 적는다(ADR 0001 재검토 기준 400ms).
